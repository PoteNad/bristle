# Security Policy

Only the latest release of Bristle receives security updates.

## Reporting a Vulnerability

Please report security issues privately through [GitHub Security Advisories](https://github.com/PoteNad/bristle/security/advisories/new) instead of opening a public issue.

Include a description of the issue, steps to reproduce it, its potential impact, and the affected Bristle and macOS versions. Reports will be reviewed as soon as possible.
